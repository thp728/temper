- **Status:** accepted
- **Date:** 2026-08-15

## Context

The assignment arrived 2026-08-14 as one line in a daily note. It is the furthest any opportunity in the pipeline has progressed — the only one of seven applications at take-home stage — and it carries a stated quality bar ("70–80% of what commercial products offer", "cannot be hello-world") that will not survive being run alongside three other commitments in the same period (a career programme, a nutrition gate and a local-inference benchmark) in a ~16-day window containing four locked office days and eight days of travel.

## Decision

Opened a dedicated project workspace in the private vault and made it the only active workstream until submission. Full entry, including everything deferred and what that costs, is in that vault's system-wide decision log.

## Alternatives considered

Track it as an application-pipeline item in the personal task tracker (rejected — it is a build with a deadline and a scope problem, not a tracker row); run it alongside the existing commitments (rejected, see above).

## Consequences

A month of broader personal progress compresses into one project. The nutrition gate lapses; the local-inference benchmark goes cold with its controlled pairs freshly completed.

## Rollback

If the assignment proves smaller than scoped, freed time goes to the local-inference artifact first — it holds the live 2026-09-06 tripwire.
